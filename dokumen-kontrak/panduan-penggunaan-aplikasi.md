# BUKU PANDUAN PENGGUNAAN APLIKASI (USER MANUAL)

- **Nama Aplikasi**: Harvest Medika SIMRS & Klinik
- **Alamat Akses**: https://simrs-klinik-medika.harvestdigital.pro

## 1. Memulai Penggunaan
1. Buka peramban (browser) pada ponsel pintar atau komputer desktop Anda, lalu kunjungi `https://simrs-klinik-medika.harvestdigital.pro`.
2. Halaman utama menampilkan ringkasan metrik real-time (Tagihan Layanan, Pasien Terlayani, dan Dokter & Poli Aktif).

## 2. Mengelola Rekam Medis & Antrean
- **Menambah Data**: Isi formulir di sisi kiri (No. Rekam Medis, Nama Pasien / Layanan, Poli / Unit, Biaya Layanan (Rp), Status Pemeriksaan), lalu tekan tombol **Simpan Data**.
- **Mencari Data**: Ketik kata kunci pada kolom pencarian di atas tabel untuk menyaring baris secara instan.
- **Ekspor ke CSV**: Tekan tombol **Ekspor CSV** untuk mengunduh laporan dalam format spreadsheet.
- **Mode Tampilan**: Gunakan tombol **Mode Tampilan** di bilah atas untuk beralih antara tema Gelap dan Terang.
